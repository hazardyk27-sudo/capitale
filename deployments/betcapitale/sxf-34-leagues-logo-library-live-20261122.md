## Explicit owner instruction
Owner selected 17 European countries, first and second divisions (34 leagues), and requested **every club's exact SXF team name mapped to a stored local badge** so a coupon labelled `Paris St-G` immediately renders `Paris St-G` badge in Match List v2, without performing any on-the-fly external lookup for today's matches. - Consulted real SXF Supabase `public.fixtures` (read-only) for the 2026-07-01 through 2027-06-30 season window. All 34 named leagues present; 1,280 fixtures contributed **575 distinct, exact SXF team strings**, not provider nicknames.

- Existing live catalog prior to this operation contained 147 SXF-aligned records, of which 93 belonged to these 34 league snapshots; **all 147 existing mappings preserved** unchanged.
- Bulk sources used **only during this initial preload**: ESPN league teams API (23 supported leagues; 305 unique newly mapped teams); FotMob `/api/data/allLeagues` and `/api/data/leagues?id=…` (all 34 exact league tables for the same 2026/27 or 2026 summer seasons; 177 remaining SXF team names). SportsDB search was attempted but rate limited (HTTP 429); no incorrect/fuzzy fallback from it was used.
- Aliases were resolved **against the exact SXF team label**, using league-restricted provider team ID/name and manually audited difficult abbreviations (reserve sides, local variants, historical club names). Examples `Paris St-G` (previously in catalog), `Man Utd`, `Jong PSV Eindhoven`, `Anderlecht B`, `Racing Genk B`, `Mardin Belediyespor`, `Van Buyuksehir Belediyespor` all retain SXF-specific catalog keys.
