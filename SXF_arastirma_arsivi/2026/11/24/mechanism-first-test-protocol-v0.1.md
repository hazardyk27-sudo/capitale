# SXF mechanism-first rescan — protocol v0.1
Date 2026-11-24. RESEARCH ONLY. Owner rejected retrospective winner-subgroup fitting. This protocol is written before executing the new calculations, but the same historical aggregate outcomes have already been inspected; November is a chronological test, NOT an untouched prospective holdout.

## Frozen tests (no threshold search)
- Use as-of exact valid checkpoints, no later information for features; original engine kernel unchanged. Exclude unverified settlements. All eligible common-coverage cases including no-signal controls where applicable. October fit, November evaluate. Unit is fixture/market/side, overlapping motor tags not independent. Preserve missing data.
- Use normalized probability p_i=(1/o_i)/sum(1/o_j), not a claim of true probability. Primary predictive metric paired mean Brier error vs p at same decision. Continuous diagnostic models fit only a single coefficient on October by binomial log loss with market logit offset (no intercept, fixed L2 penalty 1 on sum loss; feature standardized on October). Freeze then evaluate November. A fitted sign contrary to hypothesized mechanism is counterevidence. No optimize cutoffs or select by winners. Report raw sample and period results. Historical prediction metrics are not live betting performance.
- V1: test newly matched volume proportion (T8→T6) minus contemporaneous T8 normalized p, not historical money concentration. Compare vs static share minus p6. New volume is traded volume, not identified informed backing. All T6 home/away candidates with valid nonnegative increments, price 1.40–2.50; report original V1 subset on test separately. Hypothesis: positive flow excess has positive out-of-time predictive contribution beyond price.
- V2: compare native T6 V1/V2 with otherwise identical V2 3% adverse rebound rule on normalized fair odds 1/p rather than raw odds, preserving complete T9,T8,T7,T6 and 70% retention. No new threshold; audit raw-checkpoint proxy vs native and compare only common complete coverage.
- HEAVY: compare continuous log selected GBP against log selected GBP divided by prior same-league median T6 market turnover (strictly earlier dates, >=10 prior distinct fixtures; no future leakage), on V1 universe. Hypothesis relative liquidity more transferable than raw GBP; no new cutoff.
- EARLY CORE: original qualified, retained, complete-history cases at T3; test continuous origin concentration excess discounted by ratio of origin total market volume to T3 total versus undiluted origin excess. Hypothesis early evidence loses independent information as new market turnover accumulates. EARLY CORE V2: on same parent cohort test binary existing origin V2 tag (odds<2, share<95) after current p3 accounted for. No new cutoff.
- Goal model: use synchronized full 1X2 and OU/BTTS prices. Independent Poisson home/away goal model inferred from normalized 1X2 distribution, fixed numerical grid lambda 0.025 to 5.0 per team, closest squared distance in (home,draw,away); no match-result fitting. Derive P(Over2.5) and P(BTTS). Separately infer total lambda from OU2.5 normalized p, combine with 1X2-inferred home/away goal share for BTTS estimate. Independent Poisson is a hypothesis, not guaranteed realistic. Compare structural forecasts against direct market probability across all matched cases, and evaluate engine-specific subsets. Test single October coefficient for structural-minus-direct probability residual on all markets; no result-based gates.
- STABLE OVER / PREMIUM OVER: test whether 1X2-implied Over probability offers incremental information relative to direct OU probability; also test premium label on parent Stable after price via same fixed model.
- PREMIUM MIN 1.70: distinguish payout criterion from prediction. Report direct implied probability, realized win, Brier and historical gross return at SXF proxy odds on same parent, MIN and non-MIN; no threshold alteration.
- KG VAR: test goal-balance model estimate using OU total and 1X2 split, independently of previous mined BTTS filters.
- OVER STRONG: test fixed model-derived BTTS imbalance (observed BTTS probability minus balanced maximum for OU-implied total), as a continuous diagnostic of goal distribution, not raw 1.60 cutoff. No new gate; check model performance across parent Stable, separately native Strong.
- SURPRISE: non-loss target with p_team+p_draw, test incremental volume excess relative to T8 team win p (money market is 1X2), same method as V1; no win-bet conversion.
- EKOL 3: compare native first-hour and cumulative new-money shares against T8 historical money share versus T8 normalized win p, with all other prerequisites and T6 p confirmation preserved; no new parameter. Measure on identical fresh T8/7/6 V1 universe. No promotion based on retrospective rates.
- Any model with weak/negative out-of-time effect rejected or held. No production changes. Future genuinely unseen data needed before any candidate activation.
