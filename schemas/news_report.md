# NEWS v2.1 — Markdown report
Status: CANONICAL
New runs only. No mandatory JSON or validator.

For each match provide one Turkish Markdown report:
- Fixture, competition, kickoff, actual pre-match AS_OF, methodology NEWS v2.1 and research status READY/PARTIAL/BLOCKED.
- Relevant news, numbered if useful: team, fact or attributed report, direct approved-source URL, publication date/time when available (unknown if unavailable), uncertainty/contradiction, brief relevant football context where supported. Separate verified fact from uncertainty. Merge duplicate underlying stories. No news is a valid outcome.
- Compact source scan table: one row per applicable named entry, source, team scope, status FOUND / NO_RELEVANT_NEWS / INACCESSIBLE / NOT_ATTEMPTED, short result or limitation. Use genuine attempts only. A missing outlet or uncertain fact is not an unfinished scan if the required attempt was made.
- Limitations and 1–3 factual English Software findings or truthful coverage statement. No prediction, N/100 or invented news.

READY = every applicable approved source actually attempted and full report assembled. No extra research or formal quality gates required. PARTIAL/BLOCKED = actual unperformed scan/report work; report what remains. No compulsory technical audit, fixed story count or mandatory counter-tests. Research and delivery status separate.

Save the complete report in the existing authenticated NEWS browser editor after research is frozen and run routing verified. N stays null. Use real AS_OF, full Markdown, genuine source links and 1–3 English factual findings (or a truthful coverage statement). Verify actual report ID/version. If the website or export is unavailable, provide the original Markdown file when possible and report delivery separately; never invent a save. No other role edits.
